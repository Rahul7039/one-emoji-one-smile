One emoji, one smile: this entry sends the beaming grin 😁 — the warmest face a
stranger can meet at a glance. Seven candidate emojis were weighed against the
judge's brief (warmth first, then universality, a chosen rather than default pick,
and right for a stranger), and the beaming grin won: a big, toothy, eyes-smiling
grin that is joyful without a trace of intimacy or irony, instantly readable in
any culture, and a deliberate step past the plain default smileys. The program
validates the single emoji against the competition gate and writes exactly that
one character to `/output/entry.txt`, nothing else.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The program uses only the Python standard library, needs no input files and no
network, and writes exactly one emoji with no trailing newline.
